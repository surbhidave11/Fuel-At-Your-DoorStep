# Fuel-At-Your-DoorStep

## Overview
**Fuel At Your Doorstep** is a web-based application designed to provide customers with the convenience of having petrol delivered directly to their location. The website allows users to place fuel orders online, ensuring quick and efficient service with a focus on customer satisfaction and convenience.

## Features
- **User-Friendly Interface:** Simple and intuitive design for customers to easily navigate and place orders for fuel delivery.
- **Online Order Management:** Allows customers to select the type and quantity of fuel and schedule deliveries based on their preferences.
- **Real-Time Delivery Updates:** Customers can track the status of their orders in real-time and receive notifications.
- **Admin Panel:** The admin can manage customer orders, track delivery status, and oversee the system's functionality.
- **Secure Payment Integration:** Secure methods for customers to make payments directly through the website.

## Tech Stack
- **HTML/CSS:** Used for creating the front-end user interface and styling.
- **Java:** Back-end logic for handling requests, processing orders, and managing customer data.
- **Servlets:** Used to handle HTTP requests, interact with databases, and manage session data.
- **SQLYog:** A MySQL GUI tool used for database management.
- **JSP (JavaServer Pages):** Used for generating dynamic web pages based on user inputs and backend logic.
